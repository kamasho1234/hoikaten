# 空き状況の対応範囲と、探し尽くしたかの記録

最終確認: 2026-09-04

## いまの数

- **451自治体・28,869施設**（全国1,747自治体のうち26%）
- 基準日の内訳: 2026年10月 1／9月 188／8月 251／7月 7／6月 3／5月 1

母数の1,747は総務省「全国地方公共団体コード」（R6.1.1現在）の市区町村＋特別区。

## 全自治体を確認し終えている

**未確認の自治体は無い。** 1,747件すべてについて、公式サイトを開いて空き状況の
公表があるかを見た。取り込めていない約1,300件は、**そもそも公表していない**。

確認に使った探し方は4通り。どれか1つでは取りこぼすので重ねている。

| 探し方 | 何を手がかりにするか | 見つかった数 |
|---|---|---|
| リンクの文字（狭い語彙） | 「空き状況」「受入可能」 | 大半 |
| リンクの文字（広い語彙） | 「入所可能」「欠員」「定員と現員」「あき情報」など | 富谷市・吉田町ほか |
| **ページの中身** | 0〜5歳の列を持つ表があるか | 登別市・三芳町・三郷町・大台町 |
| 別ドメインの子育てサイト | トップから外に出る「子育て」リンクの先 | 0件（狛江市・竜王町は既に取り込み済み） |

道具は `scratchpad` に置いてある（vwide.py／vcontent.py／vkosodate.py／vspot.py／vresolve.py）。

## 取り込みが止まっていないかの見張り（2026-09-04に足した）

**基準日だけを見ていると、更新の取りこぼしに気づけない。** 実際に3種類の穴があった。

| 穴 | どう気づいたか | 直し方 |
|---|---|---|
| 自動更新に22自治体が入っていなかった | データはあるのにワークフローに無い、を突き合わせた | 個別ステップに無いものをまとめて回すステップを足した |
| 基準日の年・日付がずれていた（呉市2025年、熊野町が締切日） | 基準日と取得日の開きを見た | verify に日付の点検を足した（200日以上前／40日以上あとで中断） |
| 基準日を変えずに資料が差し替わっていた | 保存しているURLが404になっていた | 判定に取り込み元URLを足した。`npm run vacancy:check:sources` で404を探す |

3つとも**既存の verify では見つからなかった**。verify の検算値は基準日が変わると
照合をスキップするため。取り込み元と突き合わせる点検を別に持つこと。

## 公表していても取り込まない自治体

**空き数でないものは入れない。**

| 自治体 | 公表しているもの |
|---|---|
| 小田原市・四條畷市・由利本荘市・潟上市 | 定員と在園児、待ち人数、入所率だけ |
| さぬき市 | 園ごとに1つの状態（可能／年齢によって可能／不可）。年齢別でない |
| 守谷市 | 年齢ごとに施設名を列挙する形。施設×年齢の表に直すと印を捏造することになる |
| 芦屋市 | 施設一覧（定員・開所時間）であって空き状況ではない |

**厚木市は対象外。** 市が「空き状況は電話による回答のみ」「保育所等の空き状況を公開している
ウェブサイトがあるようですが、厚木市が承認したものではなく、実際の空き状況とは異なります」と
明記している。

## 同名の自治体の取り違えに注意

2026-09-04、**八千代町（茨城）として八千代市（千葉）のデータを公開していた**ことが分かり、
入れ替えた。取り込み済み445件すべてについて「出典ページに自治体名が出るか」を機械照合し、
これ1件だけと確かめている（`scratchpad/vname.py`）。

同じ罠は探索の段階でも出る。坂井市→堺市、湯沢市→湯沢町、十島村→豊島区、津野町→都農町、
那賀町→那珂市、香南市→江南市。**ホスト名やスラッグだけで判断しない。**
