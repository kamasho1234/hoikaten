# 空き状況ページを他自治体へ広げる（目黒区 → 川崎市）

横浜市だけの実装を汎用化し、目黒区を追加する。そのあと川崎市のPDFに挑戦する。

## 調査の結論（2026-08-17）

政令市20＋特別区23のうち、**機械可読で定期更新の空き状況を出しているのは目黒区だけ**だった。
東京都オープンデータカタログとBODIK（全国自治体の共同カタログ）をCKAN APIで横断検索し、主要市は個別に確認した。

| 自治体 | 更新 | 形式 | 項目 | 判定 |
|---|---|---|---|---|
| 横浜市 | 月1回 | CSV×3 | 受入可能数・入所待ち・在籍 | 実装済み |
| **目黒区** | **月2回** | **CSV**（BODIK・CC-BY） | 空き数(0〜5歳)・施設類型・緯度経度 | **今回追加** |
| 川崎市 | 月1回 | PDF×7区 | 受入可能数・申込数・内定数 | 次に挑戦 |
| さいたま市 | 月1回 | PDF×10区 | 不明 | 保留 |
| 大阪市 | 月1回 | 地図＋24区の個別ページ | 利用可能人数のみ | 保留 |
| 名古屋市 | **年1回**(10月頃) | Excel | 受入可能数 | 月次不可 |
| 札幌市 | — | — | 「年度途中の空き情報は公表していない」と明記 | 不可 |

- BODIK全体で「保育×空き」は4件のみ。**佐賀市は2024年5月分、横須賀市は2024年8月分で更新停止**。長浜市は定員・園児数で空き状況ではない。
- 政府の統合カタログ（data.go.jp → **data.e-gov.go.jp にリダイレクト**）は省庁データ中心で自治体データをほぼ持たない。
- **東京都カタログはBODIKからのハーベストが遅れる**（本家に7月23日分があるのにカタログ側は6月22日分が最新だった）。**取り込みはBODIK本家のAPIを使うこと。**

## 目黒区データの実測（2026年7月23日分）

- 出典ページ: https://www.city.meguro.tokyo.jp/hoiku/kosodatekyouiku/hoikuennado/akijokyo.html
- データセット: https://data.bodik.jp/dataset/131105_available_child_care （CC-BY 4.0・extras に「更新頻度=月2回」）
- **Shift_JIS**・13列固定・引用符なし・118施設
- 列: 利用調整日, 保育施設名, 施設類型, 0歳・1歳・2歳, 0歳児, 1歳児, 2歳児, 3歳児, 4歳児, 5歳児, 延長保育, 緯度, 経度
- 施設類型: 公立認可保育園13・私立認可保育園84・認定こども園4・小規模保育所11・事業所型保育所2・空欄4（家庭福祉員）
- **家庭福祉員4件だけは年齢別が空で「0歳・1歳・2歳」合算列に数値**が入る（合計5）
- 年齢別の空き合計 866。緯度経度は全118件にある
- **入所待ち人数と在籍児童数はない** → 横浜市と同じUIは出せない

## 川崎市PDFの見極め（2026-08-17・実物で確認済み）

**結論: 取り込める。** `pdfplumber` が11列の表をそのまま返す。

- ページ https://www.city.kawasaki.jp/450/page/0000030624.html にPDFリンクが539本ある。
  受入可能数は `R8_9{区}01.pdf`、利用調整結果は `kekka_R8_8{区}.pdf` という命名。
  **末尾の連番は揺れる**（`R8_9nakahara03.pdf` `kekka_R8_8asao02.pdf`）ので、ファイル名の推測ではなくページのリンクから拾うこと。
- **PDFのURLは `/450/cmsfiles/...`**。ページ内の相対リンク `../cmsfiles/...` をそのままドメイン直下につなぐと404になる。
- 列は 施設種別 / 施設名 / 住所 / 定員 / 受入年齢 / 0歳児〜5歳児。川崎区は3ページ・74施設。
- **`pdftotext` は日本語が落ちて数字だけになる**（`-layout` の有無を問わず）。`pdfplumber` の `extract_tables()` を使うこと。
- **pdfplumberの結果をコンソールに出すと文字化けするが、抽出は成功している。**
  UTF-8のファイル（JSON）に書き出してから読むこと。これで一度「復元不可」と誤判定しかけた。
- 課題: **基準日が区ごとに違う**（川崎区7月27日・中原区8月6日）。データセットの asOf をどう置くか決める必要がある。
- 課題: Python依存が増える。GitHub Actions に `actions/setup-python` と `pip install pdfplumber` を足すことになる。
