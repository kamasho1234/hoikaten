# 一時保育レコードの収集手順（サブエージェント向け）

自治体ごとの「一時保育」の記事は、`src/lib/articles/ichiji-hoiku/records/<slug>.json` の**レコード**から
組み立てる。あなたの仕事は、割り当てられた自治体について公式ページを読み、レコードを1件ずつ作ること。
文章は書かない。事実だけを、根拠の原文（quote）つきで書く。

対象は2つの制度:
1. **一時預かり事業**（一時保育）: 理由があるとき・リフレッシュで、保育園に通っていない子を一時的に預ける事業。市町村が理由の区分・上限・料金を決める
2. **こども誰でも通園制度**（乳児等通園支援事業）: 2026年度から全自治体で始まった、就労要件なし・月10時間まで（令和8・9年度は条例で3〜10時間）の通園。自治体独自の上乗せ（世田谷は月48時間）や無償化がある

## 守ること（最初に読む）

1. **サブエージェントを使わない。** 自分で curl で取り、自分で読み、自分で書く。
2. **1自治体ずつ最後まで。** 取る → 読む → JSON を書く → `LC_ALL=C.UTF-8 python scripts/verify-fact-records.py ichiji <slug>` で○にする → 次へ。
3. **推測で埋めない。** 公式ページに書いていないフィールドは JSON に入れない（記事には「記載なし」と出る）。
   書いたことはすべて `evidence` の quote で裏づける。**値は quote から読み取れる範囲を出ない。**
4. **WebFetch の要約に頼らない。** `curl -sL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/128.0 Safari/537.36" -o <保存先> <URL>` で HTML/PDF を保存し、
   タグを外してファイルに書き出し、Read で読む。PDF は pdfplumber（駄目なら pypdf、それでも駄目なら PyMuPDF で PNG にして Read で目視）。
   WebSearch は使ってよいが、**結果の URL は必ず curl で 200 を確かめてから**使う。404 なら市のサイト内で今のページを探し直す。
5. **同名自治体に注意。** 主ページ（azukariPage）の本文に、その自治体の名前が出ていることを確認する（東京都中央区・大阪市中央区など）。
6. 自治体の公式ドメインだけを出典にする。まとめサイト・保育園のサイト・社会福祉協議会（ファミサポの委託先）は不可。
7. **時間やトークンの制約は無い。** 「効率化のため簡略化」「指示待ち」「途中報告」「仮レコード」は禁止。担当分が全部○になってから1回だけ報告する。

## 探し方

1. WebSearch で `<自治体名> 一時預かり 保育園`、`<自治体名> 一時保育 利用料`、`<自治体名> こども誰でも通園制度` を検索し、公式ドメインの結果を curl で取る。
   自治体は「一時保育」「一時預かり」「ほっとステイ」「リフレッシュ保育」など独自の名前を使うことがある。
2. 一時預かりの案内ページ（利用できる理由・上限・料金が書いてあるページ）を `azukariPage` にする。料金表が別ページ・PDF ならそれも読む。
3. こども誰でも通園制度のページを探して `daredemoPage` にする。無ければ daredemo 系は全部省く（推測しない）。
4. 関連（ファミリー・サポート・センター、病児保育、休日保育、定期利用保育、ベビーシッター補助）は、一時預かりのページから案内されているものだけ `otherServices` に。

## JSON の形

`records/setagaya.json` を手本にする（形の手本。**文や値は流用しない**）。キーの意味:

| キー | 書くこと | 必須 |
|---|---|---|
| citySlug | ファイル名と同じ | 必須 |
| checkedAt | 今日の日付 `2026-09-18` | 必須 |
| azukariPage | 一時預かりの案内ページ `{label, url}`。label は「◯◯市「ページ名」」 | 必須 |
| azukariReasons | 使える理由（自治体の区分名と内容。「非定型的就労・緊急・私的理由」など） | あれば |
| azukariRefresh | リフレッシュ（私的理由・理由を問わない）で使えるか、その上限 | あれば |
| azukariLimit | 利用日数・時間の上限（月○日、年○日、週○日、連続○日。区分ごとに違えば併記） | あれば |
| azukariAges | 対象年齢（生後○か月から、○歳児クラスまで） | あれば |
| azukariFees | 料金。**区分ごとに1要素**。単位（1時間／半日／1日）と、給食・おやつ代が込みか別かを含める | あれば |
| azukariReduction | 減免（非課税世帯・ひとり親・生活保護・自治体独自の無償化） | あれば |

| azukariBooking | 予約の方法（電話・窓口・LINE・システム）と受付開始（前月○日から など） | あれば |
| azukariFacilities | 実施施設の数、一覧ページの所在 | あれば |
| daredemoPage | こども誰でも通園制度のページ `{label, url}` | あれば |
| daredemoHours | 月の利用可能時間（条例で3〜10時間。上乗せがあれば内訳） | あれば |

| daredemoAges | 対象（年齢・未就園の条件） | あれば |
| daredemoApply | 認定申請と予約の方法（つうえんポータル・窓口・独自システム） | あれば |
| daredemoFacilities | 実施施設の数、一覧の所在、実施の型（余裕活用型・一般型） | あれば |
| daredemoStatus | 実施状況（開始時期・受付状況・枠の制限） | あれば |

| sources | 参照した公式ページ `{label, url}`。azukariPage を含める | 必須 |

### evidence の quote のルール

- **その値の根拠になっている本文の一続きの文**をそのまま写す（10〜80文字）。要約・言い換え・つなぎ合わせは不可
- **ページ名・見出し・ファイル名を quote にしない**（検査で弾かれる）。「料金」「一時預かり」のような単語だけも不可
- 空白・全角半角・改行の違いは照合で無視される
- 値のあるフィールドすべてに evidence を付ける
- 料金の quote は、金額の数字が入っている文にする（例「1日 2,000円（給食費込み）」）

## これまでに出た間違い（就労証明書のときに出たもの。同じことをしない）

- **手本の quote や値を流用した**（別の自治体の文が入っていた）。手本は形だけ。文は必ず担当自治体のページから写す
- **フィールドの意味を取り違えた**（有効期限に「直近3か月の実績」）。上の表の意味どおりに。合わないものは省く
- **quote に無い内容を値に書いた**。値は quote から読み取れる範囲を出ない
- **料金の単位を落とした**。「2,000円」だけでは意味が無い。「1日2,000円（給食代別）」のように単位と食事代の扱いを書く
- **上限の主語を落とした**。「月12日まで」が児童1人あたりか、リフレッシュ区分だけか、を quote から確かめて書く
- **ページ名・ファイル名を quote にした**（「保育所（園）入所のご案内」「就労証明書（PDF形式、137KB）」）。弾かれる
- **配列に文字列を入れた**（1文字ずつに分割される）。azukariFees・otherServices・notes は必ず配列
- **短い UA を 403 で弾くサイト**がある（福岡市 kodomo.city.fukuoka.lg.jp など）。上の Chrome UA を使う
- 「トークンや時間の制約があるので簡略化する／指示を待つ」と言って止まった。制約は無い

## 終わったら

1. `LC_ALL=C.UTF-8 python scripts/verify-fact-records.py ichiji <slug1> <slug2> ...` が全件○になるまで直す
2. 担当した自治体ごとに「slug／一時預かりの上限／料金の代表例／誰でも通園の月時間／取れなかったフィールド／迷った点」を1行ずつ報告する。
   ページが見つからない自治体は、レコードを作らず、どのページを見たかを報告する

## コンテキストを使い切らないために（重要）

エージェント自身の文脈（コンテキスト）には上限がある。自治体のページは長いので、**全文を Read すると1自治体で使い切る**。
- HTML はタグを外してテキストファイルに書き出し、まず `grep -n "料金\|円\|上限\|日まで\|時間\|予約\|登録\|対象\|理由\|リフレッシュ\|誰でも通園" file.txt` で行番号を見て、**必要な行の前後だけ Read の offset/limit で読む**
- リンク一覧は「就労／一時／料金／誰でも」を含むものだけ表示する
- PDF も同様に、抽出テキストをファイルに書いて grep してから読む
- 施設一覧の表（数十行）は読まずに、件数だけ数える（`grep -c`）
- 1自治体が終わるごとに、開いたファイルは読み直さない
